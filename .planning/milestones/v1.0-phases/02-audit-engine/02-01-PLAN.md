<feature>
  <name>Audit Engine Pure Helpers</name>
  <files>packages/plugin/src/sandbox/audit/utils.ts, packages/plugin/src/sandbox/audit/utils.test.ts</files>
  <behavior>
    rgbToHex:
    - rgbToHex({ r: 0, g: 0, b: 0 }) → '#000000'
    - rgbToHex({ r: 1, g: 1, b: 1 }) → '#ffffff'
    - rgbToHex({ r: 1, g: 0, b: 0 }) → '#ff0000'
    - rgbToHex({ r: 0.502, g: 0.251, b: 0.749 }) → '#804bbf' (rounds correctly: 0.502*255=128.01→128=0x80, 0.251*255=64.005→64=0x40, 0.749*255=190.995→191=0xbf)

    buildIssueId:
    - buildIssueId('123:456', 'color', 'hardcoded-fill') → '123:456:color:hardcoded-fill'
    - buildIssueId('1:2', 'spacing', 'hardcoded-paddingLeft') → '1:2:spacing:hardcoded-paddingLeft'

    buildIssue (accepts a minimal SceneNode-like object { id, name } for testability — NOT real Figma node):
    - Returns AuditIssue with id = buildIssueId(nodeId, category, issueType)
    - Returns AuditIssue with nodeId = node.id, nodeName = node.name
    - Returns AuditIssue with pageName, category, issueType, offendingValue, suggestedFix all set

    assembleReport:
    - healthScore = Math.max(0, 100 - totalIssues): 0 issues → 100, 50 issues → 50, 150 issues → 0
    - issuesByCategory is correctly counted from the issues array
    - totalIssues = issues.length
    - totalTokens = tokens.length
    - totalComponents = components.length
    - schemaVersion matches import from @ai-ds-auditor/shared
  </behavior>
  <implementation>
    After tests pass (RED then GREEN):

    utils.ts implements:
    1. rgbToHex(rgb: RGB): string — Math.round(rgb.r * 255).toString(16).padStart(2, '0') for each channel
    2. buildIssueId(nodeId: string, category: string, issueType: string): string — concatenate with colons
    3. buildIssue(node: { id: string; name: string }, pageName: string, category: AuditIssue['category'], issueType: string, offendingValue: string, suggestedFix: string): AuditIssue — constructs full AuditIssue
    4. assembleReport(issues: AuditIssue[], components: ComponentSpec[], tokens: DesignToken[], fileId: string, fileName: string): AuditReport — uses schemaVersion from @shared, computes summary fields, sets scannedAt to new Date().toISOString()

    CRITICAL: utils.ts imports `schemaVersion` from '@shared/index' (path alias). It imports `AuditIssue`, `AuditReport`, etc. as `type` imports. The RGB type parameter in rgbToHex should be typed as `{ r: number; g: number; b: number }` (not importing from @figma/plugin-typings) so the function can be called from tests without a Figma runtime.
