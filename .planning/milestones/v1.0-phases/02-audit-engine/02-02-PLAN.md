Figma Plugin API types (from @figma/plugin-typings, available in sandbox tsconfig):
- `figma.mixed` — Symbol sentinel for mixed values on text nodes
- `SceneNode` — base type for all scene graph nodes
- `TextNode` — text node with .textStyleId, .fontSize, .fontWeight, .boundVariables
- `FrameNode | ComponentNode | InstanceNode` — have .layoutMode, .paddingLeft/Right/Top/Bottom, .itemSpacing, .boundVariables
- `SolidPaint` — has .type === 'SOLID', .color (RGB), .boundVariables?.color (VariableAlias | undefined)
- `VariableAlias` — { type: 'VARIABLE_ALIAS', id: string } — presence means field is variable-bound
- `GeometryMixin` — .fillStyleId: string | PluginAPI['mixed'], .strokeStyleId: string | PluginAPI['mixed']
- `VariablesMixin` — .boundVariables: Record of VariableBindableNodeField → VariableAlias

  <action>
    Create `packages/plugin/src/sandbox/audit/color.ts`:

    Export two functions: `auditFills` and `auditStrokes`. Both take `(node: SceneNode, pageName: string, styleIds: Set<string>)` and return `AuditIssue[]`.

    auditFills logic:
    1. If `!('fills' in node)` return []
    2. Get fills: `const fills = node.fills`
    3. If `fills === figma.mixed` return [] (mixed text fills — skip at node level)
    4. Check fillStyleId: if `'fillStyleId' in node`, get id. If id !== figma.mixed && id !== '' && styleIds.has(id as string), return [] (bound to style — OK)
    5. Iterate fills: for each fill, `if (fill.type !== 'SOLID') continue` (gradients/images cannot be variable-bound)
    6. If `!fill.boundVariables?.color`: flag as hardcoded. Convert fill.color with rgbToHex, push buildIssue(node, pageName, 'color', 'hardcoded-fill', hex, 'Bind to a color variable or apply a paint style')
    7. Return issues

    auditStrokes logic — identical pattern but using `node.strokes` and `node.strokeStyleId`:
    1. If `!('strokes' in node)` return []
    2. Get strokes array, check strokeStyleId against styleIds
    3. For each SOLID stroke with no boundVariables.color: flag 'hardcoded-stroke' with rgbToHex hex value

    Import: `import { buildIssue, rgbToHex } from './utils';`
    Import: `import type { AuditIssue } from '@shared/index';`

    ---

    Create `packages/plugin/src/sandbox/audit/typography.ts`:

    Export one function: `auditTypography(node: TextNode, pageName: string, styleIds: Set<string>): AuditIssue[]`

    Logic:
    1. Check textStyleId: `const textStyleId = node.textStyleId`. If `textStyleId !== figma.mixed && textStyleId !== '' && styleIds.has(textStyleId as string)` return [] (bound to text style — OK)
    2. Check boundVariables: `const boundVars = node.boundVariables`
    3. Check fontSize: `if (!boundVars?.fontSize && node.fontSize !== figma.mixed)` push buildIssue with category 'typography', issueType 'hardcoded-fontSize', offendingValue String(node.fontSize), suggestedFix 'Apply a text style or bind fontSize to a variable'
    4. Check fontWeight: `if (!boundVars?.fontWeight && !boundVars?.fontSize && node.fontWeight !== figma.mixed)` push buildIssue with issueType 'hardcoded-fontWeight', offendingValue String(node.fontWeight), suggestedFix 'Apply a text style or bind fontName to a variable'
    5. Return issues

    Import: `import { buildIssue } from './utils';`
    Import: `import type { AuditIssue } from '@shared/index';`

    CRITICAL pitfall guard: Always check `node.fontSize !== figma.mixed` before calling `String(node.fontSize)`. Otherwise offendingValue becomes 'Symbol(figma.mixed)'.

    Export: `auditSpacing(node: FrameNode | ComponentNode | InstanceNode, pageName: string): AuditIssue[]`

    Logic:
    1. `if (node.layoutMode === 'NONE') return []` — only auto-layout nodes have meaningful padding
    2. `const bv = node.boundVariables`
    3. Define fields: `const spacingFields = ['paddingLeft', 'paddingRight', 'paddingTop', 'paddingBottom', 'itemSpacing'] as const`
    4. For each field in spacingFields:
       - Skip if `bv?.[field]` exists (VariableAlias present — bound to variable)
       - Get value: `const value = node[field]` (these are always `number` on auto-layout nodes, not mixed)
       - Skip if `value === 0` — zero is intentional, not noise (RESEARCH Pitfall 8)
       - Push buildIssue with category 'spacing', issueType `hardcoded-${field}`, offendingValue String(value), suggestedFix `Bind ${field} to a spacing variable`
    5. Return issues

    Import: `import { buildIssue } from './utils';`
    Import: `import type { AuditIssue } from '@shared/index';`

    2. `if (!componentNames.has(node.name)) return []`
    3. Return `[buildIssue(node, pageName, 'component', 'disconnected-component', node.name, `Replace this ${node.type} with an instance of the "${node.name}" component`)]`

    Note: InstanceNode.type === 'INSTANCE', ComponentNode.type === 'COMPONENT' — these are excluded by the type check. Only FRAME and GROUP get flagged, which is the correct behavior (instances are already connected).
