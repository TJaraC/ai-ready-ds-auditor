**Message handling — useEffect with window.addEventListener('message'):**
Map each SandboxMessage type to state transitions:
- `SCAN_PROGRESS` → setScanProgress({ percent, currentNode })
- `SCAN_COMPLETE` → NOT used directly (the combined flow sends INJECT_DATA automatically after scan — see button logic below); if received without an INJECT_DATA in flight, just update report state
- `SCAN_ERROR` → setPhase('error'), setErrorMessage(msg.message)
- `INJECT_COMPLETE` → setPhase('complete'), setReport(stored report — see design note), setIsOutOfSync(false), setScanProgress(null)
- `INJECT_ERROR` → setPhase('error'), setErrorMessage(msg.message)
- `SYNC_OUTDATED` → setIsOutOfSync(true)

DESIGN NOTE: The INJECT_DATA sandbox handler runs runAudit() then injectReport() atomically. The UI only sends `INJECT_DATA` and receives `INJECT_COMPLETE` with bytesWritten/chunkCount — it does NOT receive the report back from the sandbox in this flow. The report was previously received via SCAN_COMPLETE if START_SCAN was used, but in the combined flow the sandbox does not send SCAN_COMPLETE at all. To keep the UI able to display the dashboard after injection, one of two approaches:
- (SIMPLER) Keep sending `SCAN_COMPLETE` from the INJECT_DATA handler after audit completes but before injection. The UI updates `report` state on SCAN_COMPLETE, then transitions to `complete` on INJECT_COMPLETE.
- OR: Request the UI thread to store the report locally in state from SCAN_COMPLETE only.

Use the SIMPLER approach: the INJECT_DATA handler in code.ts WILL send SCAN_COMPLETE with the report, then INJECT_COMPLETE. The UI listens for both. On SCAN_COMPLETE, update report and set phase to 'injecting'. On INJECT_COMPLETE, set phase to 'complete'.

NOTE TO EXECUTOR: Plan 03-01 Task 2 does not yet send SCAN_COMPLETE from the INJECT_DATA handler. Add it there OR add it here as a note. Since 03-01 and 03-02 run in parallel, the executor of 03-01 should send SCAN_COMPLETE before INJECT_COMPLETE from the INJECT_DATA case. If 03-01 is already done and did not include this, add a short note in the SUMMARY that 03-03 must patch code.ts to emit SCAN_COMPLETE from the INJECT_DATA handler.

     const url = URL.createObjectURL(blob);
     const a = document.createElement('a');
     a.href = url;
